# Kael

### Knowledge Amplification & Execution Layer

Tools and patterns that keep the thinking yours.

Most AI tooling optimizes for delegation: hand off the task, approve the
output, move on. Kael does the opposite. The deterministic parts run in
code, not in the model, so execution stays reliable. And instead of
handing you a finished draft to rubber-stamp, it does the mechanical work
and hands the thinking back to you.

The name is a backronym:

- **Knowledge**: the ground. A living second brain, memory that
  accumulates instead of resetting.
- **Amplification**: the thesis. AI should amplify how you think, not
  think for you.
- **Execution**: the guarantee. The model orchestrates, the code runs.
  Determinism where it matters.
- **Layer**: the boundary. Everything lives in the harness between the
  human and the model.

## Principles

- Amplification clears the path to your judgment. Delegation makes the
  call for you.
- You stay in the loop because you want to think, not because you have to.
- Knowledge compounds; context should never start from zero.
- Deterministic work belongs in code, not in prompts.
