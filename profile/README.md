# Kael

### Keep Agency, Extend Leverage

Every AI project we build lives here. They all share one thesis: AI should
amplify the human, not replace them.

## Principle

**Friction where the thinking happens.** We add steps that are tedious on
purpose. The thinking about the problem comes from the person, never
autocompleted by the model. Without that step people don't think, they take the
fastest path available. We would rather be slower than produce work nobody
thought through.
